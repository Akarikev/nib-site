# Nib Site (`nib.elorm.xyz`)

Official web experience and Google Play Privacy Policy site for **Nib** (`com.nib.game`).

## Live URLs

- **Web Studio & App**: https://nib.elorm.xyz *(also mirrored on EAS Hosting at https://elormtsx-nib.expo.app)*
- **Official Privacy Policy (Google Play URL)**: https://nib.elorm.xyz/privacy

## Deploying on Vercel (`nib.elorm.xyz`)

1. Import **`Akarikev/nib-site`** in your [Vercel Dashboard](https://vercel.com/new).
2. Vercel automatically detects `vercel.json` (`outputDirectory: "public"` and clean URL rewrite for `/privacy`).
3. Go to **Project Settings → Domains** and add **`nib.elorm.xyz`**.

## Local Preview

```sh
bun run start
```
